# 📦 The Blanket Box (TBB) - 1,021 HTML Unblocked Games.

Welcome to the **Blanket Box (TBB) HTML Games Collection**—a clean, lightweight, and completely unblocked archive of **1,021 classic web games**. 

This repository was built out of a passion for digital preservation. It provides a hassle-free, distraction-free environment for students, developers, and retro-game enthusiasts to play timeless web classics directly in the browser without dealing with heavy ads, pop-ups, or network restrictions.

---

## 🔍 Is This Project Legit? (Addressing Skepticism)

We understand that a repository offering over a thousand unblocked games can look "too good to be true" or raise security red flags. Here is exactly how this project works and why it is safe:

*   **100% Open Source & Transparent:** Every single game file in this repository is plain text HTML, CSS, and JavaScript. There are no compiled binaries (`.exe`, `.msi`), no hidden installers, and no obfuscated scripts. You can inspect every line of code yourself right here on GitHub.
*   **Zero External Trackers or Ads:** Traditional "unblocked games" websites are often bloated with malicious advertisements, tracking cookies, and forced redirects. Because this project runs entirely out of a clean GitHub repository (or via GitHub Pages), there are absolutely no ads, no trackers, and no data collection.
*   **No Flash Player Required:** Adobe Flash was officially deprecated in 2020. Every game in this archive runs natively on modern web standards (HTML5, WebGL, Canvas, and WebAssembly). They require no sketchy browser extensions or third-party plugins to run.
*   **Locally Playable:** If you don't trust hosting networks, you can download or clone this entire repository to your local machine and play every single game completely offline.

## 🛠️ Technical Architecture

This project is built to be as minimal and lightweight as possible. 

### Performance & Optimization
*   **Static Hosting:** Because the entire project consists of static files, it can be hosted flawlessly for free using **GitHub Pages**, **Vercel**, or **Netlify**.
*   **Minimal Payload:** Games are stripped of unnecessary third-party marketing APIs, making them load instantly even on restricted, low-bandwidth school or workplace networks.
*   **Responsive Framework:** The launcher dashboard is fully responsive, allowing you to browse and play games on desktops, laptops, tablets, and smartphones.
